# PickWise 인증 화면 디자인 개선

## 적용 범위

로그인·회원가입·세션 복원 대기 화면을 다듬었다. 기존 PickWise 로고 파일과 앱 테마의 색상은 유지했다. 인증 API·세션 정책은 변경하지 않았다.

## 참고한 자료

아래 자료는 각 앱의 공개 디자인 패턴을 정리한 getdesign의 독립 분석이다. 앱 공식 디자인 규격이라고 주장하지 않는다.

| 참고 | 가져온 구성 원칙 | PickWise 반영 |
| --- | --- | --- |
| [Airbnb](https://getdesign.md/airbnb/design-md) | 읽기 편한 간격과 단순한 입력 구조 | 입력창과 버튼 크기, 여백의 일관성 |
| [Nike](https://getdesign.md/nike/design-md) | 브랜드의 크기와 명확한 시각적 우선순위 | 첫 화면에서 원래 로고를 크게 표시 |
| [Notion](https://getdesign.md/notion/design-md) | 조용한 기본 화면과 간결한 폼 | 불필요한 장식 아이콘 제거, 짧은 제목·설명 |

각 서비스의 색상·로고·문구는 가져오지 않았다. PickWise의 기존 흰색·회색·녹색 테마를 사용한다.

## 로고가 작았던 원인과 해결

원본 PNG는 1707×469이고 실제 로고의 알파 영역은 `(107, 117) ~ (924, 352)`이다. 기존 200px 이미지 박스 안에서 실제 로고 폭은 약 96px였다. 이제 이미지 파일을 수정하지 않고 Flutter의 표시 영역에서 투명 여백을 제외한다.

실제 로고의 표시 폭은 기본 280px이며 작은 화면에서는 가용 너비로 줄어든다. 817:235 비율을 유지하며 전체 로고의 형태·색·파일은 바꾸지 않았다. 인증 화면에만 적용한다.

## 구성과 동작

- 로고·제목·입력창·버튼의 왼쪽 기준선을 맞췄다.
- 빈 상단 AppBar는 진입 화면에서 제거하고 뒤로 갈 수 있을 때만 표시한다.
- 로그인은 기존 테마의 주 버튼, 회원가입은 테두리 버튼, 게스트 이용은 보조 링크로 구분한다.
- 입력창은 같은 높이와 모서리 반경을 사용하고 포커스 테두리로 현재 입력 위치를 표시한다.
- 등장 시 260ms의 짧은 페이드·이동, 포커스 전환, 오류 영역의 160ms 크기 전환을 적용한다. 동작 줄이기 설정에서는 사용자 지정 애니메이션을 생략한다.
- 작은 화면과 키보드에서는 스크롤할 수 있고, 스크롤로 키보드를 닫을 수 있다.
- 기존 로그인·가입·세션 복원·게스트·오류 처리 흐름을 유지한다.

## 확인

Flutter 위젯 렌더링으로 두 화면의 PNG를 만들고 직접 확인했다. 로고 표시 크기·비율, 작은 화면·확대 글자·키보드, 로그인·회원가입·뒤로 이동·세션 복원 테스트를 수행했다. PNG 확인에 쓴 일회성 렌더 테스트는 프로젝트에서 제거했다. Device Hub 또는 시뮬레이터를 직접 제어하지 않았다.
