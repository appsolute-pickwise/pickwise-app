# PickWise 상품 데이터 API 조사

> 조사일: 2026년 10월 28일  
> 범위: 팀원 C의 제품 비교(05) · 제품 상세(06) · 가격 확인(07)  
> 구분: 공개된 공식 문서 조사. API 키가 필요한 실시간 성공 응답 검증은 아직 하지 않았다.

## 결론 먼저

1. **네이버 쇼핑 검색 API는 지금 사용할 수 없다.** 네이버 공식 공지에 따라 2026년 7월 31일 종료됐고, NAVER API HUB에도 대체 쇼핑 상품 검색 API는 없다. [네이버 종료 공지](https://developers.naver.com/notice/article/32530)
2. **현재 가장 먼저 시험할 공식 소매 API는 11번가 Open API다.** 무료 API로 상품 검색과 상품 상세 조회를 제공하며, 문서에는 상품 가격·할인가·판매자·배송 정보·상품 링크가 나온다. 단, 11번가 상품만 조회한다. [11번가 상품 검색 문서](https://openapi.11st.co.kr/openapi/OpenApiGuide.tmall) · [상품 정보 조회 문서](https://openapi.11st.co.kr/openapi/OpenApiGuide.tmall?commonGuideNo=3)
3. **이어폰 사양은 MVP에서 JSON 직접 관리가 가장 현실적이다.** 11번가 가격 API의 필드는 상품·판매 정보 중심이다. Icecat 같은 제품 카탈로그도 후보지만 브랜드·제품 커버리지와 이용 허용 범위를 모델별로 확인해야 한다.
4. **여러 쇼핑몰 가격을 합쳐 주는 확인된 공식 무료 API는 찾지 못했다.** 유료 데이터 제공업체나 가격비교 사업자와의 제휴는 후보지만, 커버리지·정확도·사용권을 확인해야 한다. 이는 조사한 공개 문서에 근거한 판단이며, 비공개 제휴 API가 전혀 없다는 뜻은 아니다.
5. **현재 앱에 API 키를 넣지 않는다.** 외부 키를 쓰는 API는 서버에서 중계하고, 키는 앱에 포함하지 않는다. 우선 호출 한 번으로 필드·인코딩·키 제한·정확한 제품 일치 여부를 확인한 뒤 도입을 결정한다.

## 1. 11번가 Open API: 가장 먼저 테스트할 후보

공식 개발 가이드에 `ProductSearch`와 `ProductInfo`가 있다. 검색은 키워드, 페이지 번호, 페이지 크기(기본 50, 최대 200), 가격순(`sortCd=L`) 등을 받는다. 상세 조회는 `productCode`를 받고 기본 가격·최저가·이미지·배송비·옵션을 돌려주는 예시가 문서화돼 있다. [상품 검색](https://openapi.11st.co.kr/openapi/OpenApiGuide.tmall) · [상품 상세 조회](https://openapi.11st.co.kr/openapi/OpenApiGuide.tmall?commonGuideNo=3)

### 문서에 나온 검색 응답 필드

- `ProductCode`, `ProductName`, `ProductImage` 또는 이미지 주소, `DetailPageUrl`
- `ProductPrice`, `SalePrice`, `Seller`, `Rating`, `ReviewCount`
- `Delivery`, 할인·포인트·무이자 정보
- 상세 조회에는 `LowestPrice`, `ShipFee`, 추가 이미지와 상품 옵션 필드가 예시로 있음

### 확인되지 않은 부분

- 문서 샘플은 오래된 상품과 XML/EUC-KR 형식이다. 현재도 응답 구조와 문자 인코딩이 그대로인지 알 수 없다.
- 문서 요청 예시는 `http://`를 사용한다. HTTPS 주소가 동작하는지 확인하기 전에는 키를 포함한 요청을 앱에서 직접 보내면 안 된다.
- 개발 가이드에는 초당/일일 한도가 명확히 표시되지 않는다. 초과 오류 코드만 안내돼 있다.
- 판매 상품 검색 결과가 반환된다고 해서 모델·세대·색상 옵션이 정확히 일치한다는 보장은 없다.
- 검색 가격과 배송 정보가 실제 결제 단계의 쿠폰·회원 혜택·주소별 배송비까지 반영하는지 검증해야 한다.

### 등록 후 최소 검증

11번가 Open API Center에서 개발자 계정과 서비스 키를 발급받는다. 공식 안내에는 인증키 180일 유효기간 정책 공지가 있으므로 만료·연장 방식을 같이 확인한다. [11번가 Open API Center](https://openapi.11st.co.kr/openapi/OpenApiFrontMain.tmall)

다음 세 상품으로 먼저 조회한다.

1. Sony WF-1000XM5
2. Samsung Galaxy Buds3 Pro
3. Apple AirPods Pro 3

각 상품에 대해 `ProductSearch`를 호출하고, 정확한 `ProductCode`를 골라 `ProductInfo`를 한 번 더 호출한다. 검색어 결과를 그대로 제품의 최저가로 간주하지 않는다.

| 검증 항목 | 통과 조건 |
|---|---|
| 연결·인증 | HTTPS로 요청 가능한지 확인하고 정상 JSON/XML 응답 및 오류 응답을 구분 |
| 인코딩 | 한글 상품명이 깨지지 않고 JSON/XML 파서가 처리 가능 |
| 제품 일치 | 모델명·세대·옵션이 대상 JSON 제품과 동일한 결과를 식별 가능 |
| 가격 | API 값과 해당 11번가 상세페이지 값을 같은 시점에 대조 |
| 배송 | 무료/유료 배송 필드가 실제 상세페이지와 일치하는지 확인 |
| 상품 옵션 | 색상·구성·세대가 다른 결과를 걸러낼 수 있는지 확인 |
| 호출 제한 | 일일/초당 한도, 재시도 간격, 키 만료 정책 확인 |
| 사용 조건 | 가격·이미지·응답 저장, 캐시, 앱 표시, 상업적 이용 조건 확인 |

3개 모델 중 2개 이상에서 정확한 상품과 가격·배송 필드가 안정적으로 확인되면 **11번가 전용 구매처 정보**로 한정해 붙일 수 있다. 이 결과를 전체 쇼핑몰 최저가라고 표현하면 안 된다.

## 2. 네이버 API 현황: 기존 계획 수정 필요

네이버 개발자센터의 Search API 중 쇼핑 검색은 2026년 7월 31일 종료됐고, 기존 키도 2026년 8월 1일부터 호출할 수 없다. 네이버 공식 공지는 쇼핑 검색을 NAVER API HUB 이관 대상에서 제외하고 대체 API도 제공하지 않는다고 명시한다. [네이버 공식 종료·이관 공지](https://developers.naver.com/notice/article/32530)

NAVER API HUB에는 일반 검색, 검색어 트렌드, 쇼핑 인사이트가 있지만 쇼핑 인사이트는 카테고리·키워드 클릭 추이 데이터다. 상품 단위 현재 가격·판매처·상세 스펙을 대신 제공하지 않는다. [NAVER API HUB 개요](https://api.ncloud-docs.com/docs/naver-api-hub-overview)

네이버 커머스 API는 스마트스토어 판매자가 자기 스토어의 상품·주문 등 주요 기능을 HTTP API로 다루는 API다. 상품 검색도 판매자/채널 상품번호나 판매자 관리 코드로 관리 상품을 조회하는 기능이므로, 전 쇼핑몰 소비자 상품 검색용 API와 다르다. [커머스 API 소개](https://apicenter.commerce.naver.com/docs/introduction) · [상품 목록 조회](https://apicenter.commerce.naver.com/docs/commerce-api/current/search-product)

## 3. 다나와·에누리·다중 판매처 가격

### 다나와

다나와의 과거 Open API 문서에는 상품 코드 기반 정보·가격 정보 API 메뉴가 남아 있다. 하지만 공개 페이지의 오래된 경로와 불완전한 문서만으로 현재 발급·호출 가능 여부를 확정할 수 없다. [다나와 Open API 문서 페이지](https://img.danawa.com/new/open_api/api_guide.html)

별도로 ReefAPI가 다나와 검색, 판매처별 가격, 배송, 사양, 가격 이력을 JSON API로 제공한다고 안내한다. 다나와 공식 API가 아니며 다나와와 제휴하지 않았다고 스스로 밝히고 있으므로, 실제 검토 시에는 이용약관·데이터 보관/재배포·출처 표기·서비스 중단 시 대체 방식을 먼저 확인한다. [ReefAPI 다나와 API](https://reefapi.com/ko/danawa-api)

### 에누리

에누리 공개 안내는 판매자 입점, 상품 DB 연동, 상품정보 제공에 초점이 있다. 판매자용 가격비교 연동에는 사업자 서류와 비용·수수료 조건이 제시돼 있다. 일반 앱 개발자가 임의의 소비자 상품검색 API 키를 발급받는 공개 문서는 찾지 못했다. [에누리 판매자 입점·연동 안내](https://seller.enuri.com/sdul/Sdu_Guide.jsp?view=alliance03)

### 정리

다나와/에누리 가격을 앱에 그대로 가져오려면 공개 API라고 가정하지 말고 데이터 제공·제휴 여부를 직접 확인한다. 브라우저 페이지를 긁는 비공식 라이브러리는 페이지 변경, 차단, 데이터 사용권 문제 때문에 제품 기능의 핵심 경로로 권하지 않는다.

DataForSEO의 Google Shopping Merchant API는 상품 검색 결과, 판매자별 가격, 배송·구매 조건, 상품 사양을 JSON 형태로 제공한다고 문서화돼 있다. 일반 API 가격 안내에는 신규 계정 시험용 $1 크레딧, 일반 최소 충전 $50, 상품/판매처 표준 처리 약 $0.001/항목이 표시돼 있다. 실제 과금은 엔드포인트·처리 우선순위에 따라 달라진다. [Google Shopping Merchant API](https://dataforseo.com/apis/merchant-api) · [가격](https://dataforseo.com/pricing/merchant) · [제품 상세 응답 필드](https://docs.dataforseo.com/v3/merchant-google-product_info-task_get-advanced/)

한국 위치·한국어 결과를 요청할 수 있는 위치 코드가 제공되는지, 이어폰 3개가 실제 한국 판매처와 원화 가격으로 잡히는지 먼저 검증한다. 검색 결과는 Google Shopping에 실린 데이터이며 네이버/다나와 전체 판매처 목록과 같지 않다.

### SerpApi Google Shopping API

SerpApi는 Google Shopping 검색 결과를 구조화하고 `gl=kr`을 지원한다고 문서화한다. 가격, 판매처, 배송 문자열, 링크 등을 제공할 수 있다. 공식 가격 페이지 기준 무료 월 250회, Starter 월 $25/1,000회다. [Google Shopping API](https://serpapi.com/google-shopping-api) · [국가 코드](https://serpapi.com/google-shopping-countries) · [가격](https://serpapi.com/pricing)

이는 Google의 공식 상품 검색 API가 아니라 SerpApi가 Google Shopping 결과를 수집·파싱하는 서비스다. 한국 상품 검색의 정확성, API 데이터 저장·표시권, 서비스 이용약관, 장애·요금 변경을 확인해야 한다. 검색 결과가 잘 나온다는 이유만으로 제조사 사양의 근거로 사용하지 않는다.

## 5. 제품 사양·이미지 후보

### 제조사 공식 자료 + JSON 직접 관리

현재 20~30개 모델은 제품 JSON에 필요한 사양을 직접 입력하고, 제조사 공식 사양 페이지를 `sourceUrl`로 저장하는 방식이 가장 작고 설명하기 쉽다. 사양 변경 시 확인일과 조건을 사람이 검토할 수 있다. 가격 API가 바뀌어도 제품 상세·비교 기능이 무너지지 않는다.

### Icecat

Open Icecat은 등록 후 접근할 수 있는 무료 제품 카탈로그이며, 참여 브랜드의 다국어 제품 설명·이미지·사양을 제공한다고 안내한다. Full Icecat은 더 넓은 유료 범위다. 모델이 등록돼 있는지 검색하고, JSON 필드가 PickWise 기준과 맞는지 확인해야 한다. [Open Icecat 안내](https://icecat.com/content-subscription/) · [Open Content License](https://iceclog.com/open-content-license/)

무료 공개라고 데이터 사용 조건이 없는 것은 아니다. 콘텐츠 복제·배포에는 라이선스 조건이 있으므로 앱에서의 표시, 출처표시, 캐시, 상업적 이용을 확인하고 적용한다.

### GS1 Verified by GS1

GTIN/바코드로 제품·브랜드 식별의 기초 정보를 확인하는 용도다. 일반 웹 조회는 일 30건까지이며, 더 많은 조회와 API는 지역 GS1 회원기관을 통해 문의해야 한다. 배터리·무게·ANC·가격을 제공하는 사양 API는 아니다. [Verified by GS1 안내](https://support.gs1.org/support/solutions/articles/43000734077-what-is-verified-by-gs1-)

### KC 인증·리콜 정보

제품안전정보센터는 KC 인증정보와 국내·외 리콜 정보를 Open API로 제공하며 신청서와 인터페이스 설계서를 제공한다. 가격비교의 핵심은 아니지만, 제품 상세에 인증·리콜 확인 기능을 더하는 후속 차별화 후보가 될 수 있다. 모델명 또는 인증번호로 실제 이어폰 데이터가 식별되는지 먼저 시험한다. [제품안전정보센터 Open API](https://www.safetykorea.kr/release/openapi)

## 6. 해외 마켓 API: 국내 가격 기능의 대체재는 아님

- **Amazon Creators API:** Amazon 상품 검색·상세·변형·이미지·오퍼용이다. 기존 PA-API 5는 폐기 수순이며 Creators API로 이전됐다. Amazon Associates 가입, 최근 30일 10건의 적격 판매, 별도 API 등록이 필요하다. Amazon 마켓 안에서만 쓸 수 있어 국내 네이버/다나와 가격 비교 대체재가 아니다. [Creators API 문서](https://affiliate-program.amazon.com/creatorsapi/docs/) · [PA-API 폐기 공지](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/paapiv5-deprecation)
- **eBay Browse API:** 키워드·카테고리·GTIN 검색과 상품 상세, 판매자·배송 관련 정보를 제공한다. OAuth 앱 토큰이 필요하고 eBay 판매 상품에 한정된다. 해외 직구 가격 비교를 추가할 때만 고려한다. [eBay Browse API](https://developer.ebay.com/api-docs/buy/api-browse.html)
- **Google Merchant API:** 판매자가 자신의 상품 피드·계정·리스팅을 관리하는 API다. 임의의 소비자 쇼핑 검색 결과를 조회하는 API가 아니다. 공개 상품 검색 자료가 필요하면 Google Shopping 결과를 제공하는 데이터 공급자와 목적·이용권한을 따로 확인해야 한다.

## 권장 적용 순서

### MVP

1. 제품명·가격·비교 사양은 현재 JSON 카탈로그를 유지한다.
2. 가격 버튼은 제품별 가격비교 링크로 연결한다.
3. 11번가 API 키를 발급할 수 있으면 위 3개 이어폰으로 `ProductSearch`와 `ProductInfo`만 시험한다. 이 단계에서 API를 앱에 붙이거나 키를 소스 코드에 저장하지 않는다.
4. 응답이 안정적이면 가격 확인 화면에 **11번가 가격**임을 명시해 제한적으로 추가하고, 실패 시 기존 가격비교 링크를 유지한다.

### MVP 이후

1. 다중 판매처 가격이 핵심 기능이 되면 DataForSEO와 SerpApi를 같은 3개 제품으로 소액/무료 할당량 파일럿한다.
2. 상품 정확도, 원화·배송 필드, 데이터 갱신, 캐시·표시 권한, 비용을 비교한다.
3. 사양 자동 보강은 Icecat에서 현재 카탈로그 모델의 커버리지를 확인한 뒤 적용 여부를 결정한다.
4. 출처·가격 스냅샷 저장, 목표가 알림, 리콜 정보는 데이터 제공권과 운영 인프라가 정해진 후 구현한다.

## API 키와 호출 구조

- Flutter 앱에 비밀 키를 넣지 않는다. 앱 바이너리에서 추출될 수 있다.
- 호출이 필요한 API는 서버의 작은 프록시 엔드포인트를 통해 호출한다. 키를 서버 환경변수/비밀 저장소에 두고 응답에서 키를 제거한다.
- MVP에 DB가 없더라도 프록시만 두는 방식은 가능하다. 응답을 저장하지 않고 전달하는 것과, 가격 이력을 저장하는 것은 별도 결정이다.
- 서버 로그, 오류 로그, 분석 로그에 키가 남지 않는지 확인한다. 특히 API 문서가 키를 URL 쿼리 파라미터로 받으면 전체 URL 로깅을 끈다.
- API 호출 실패·한도 초과·빈 검색·오래된 데이터는 오류와 최신 가격을 구분해서 처리한다.
- 이미지 URL을 API에서 받더라도 이미지 재호스팅과 캐시는 저작권·API 약관 확인 후 진행한다.

## 최종 추천

**MVP에는 네이버 API 대신 JSON 카탈로그와 가격비교 페이지 링크를 유지하고, 11번가 API를 먼저 소규모로 실호출 검증한다.** 11번가 API는 무료 공식 검색 경로지만 11번가 한 곳의 판매 결과만 제공하므로, 이를 시장 전체 최저가라고 표현할 수 없다.

**MVP 이후 다중 판매처 가격을 원하면** 다나와/에누리에는 공식 데이터 제휴 가능성을 문의하고, 병행해서 DataForSEO 또는 SerpApi로 한국 결과를 비교한다. **사양 데이터는** 제조사 공식 출처가 있는 JSON을 기준으로 유지하고, Icecat은 실제 제품 커버리지와 라이선스가 확인될 때만 보조로 쓴다.
