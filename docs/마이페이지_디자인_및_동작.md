# PickWise 마이페이지

## 디자인 방향과 참고 자료

기존 흰색·회색·녹색 테마와 로고를 유지한다. 계정 상태와 실제 이용 중인 비교를 먼저 보여주고 나머지 메뉴는 단순한 목록으로 정리한다. 색상 테마를 변경하지 않았다.

getdesign 자료는 각 서비스 공식 규격이 아닌 공개 패턴의 독립 분석이다. 타 서비스의 색상·로고·문구는 가져오지 않았다.

## 구성

1. 계정 요약: 실제 이메일과 로그인 여부. 등록하지 않은 닉네임·프로필 사진을 생성하지 않는다.
2. 현재 비교: 실제 선택 수와 제품명. 누르면 기존 비교 탭으로 이동한다.
3. 기본 취향: 저장한 우선순위·예산·착용 형태·필수 조건. 수정 버튼으로 편집한다.
4. 저장한 비교: 기존 서버 기록 화면으로 연결한다.
5. 앱 정보: Flutter의 앱 정보·라이선스 보기를 사용한다.
6. 로그아웃: 확인·취소가 가능하며 실제 세션 폐기에 연결한다.

게스트는 로그인·회원가입으로 이동할 수 있고 기본 취향은 기기에 별도로 저장한다. 저장한 비교를 열면 기존 로그인 화면을 사용한다.

## 연결과 데이터 보호

- 하단 탭은 홈 0·탐색 1·비교 2·마이 3이며 기존 탭 순서를 유지한다.
- 하단 바는 기본 56px이며 큰 글자에서는 확장한다. 스크롤해도 표시하고 기존 선택 표시와 색상은 유지한다.
- 기본 취향 편집은 `LikingScreen(editDefault: true)`이며 추천 실행과 분리한다.
- `SessionProvider.saveDefaultPreferences(preferences: ...)`로 지정한 취향만 서버에 저장한다. 진행 중인 비교 목록과 선택 기준을 덮지 않는다.
- 조회 재시도는 `loadDefaultPreferences(applyToSelection: false)`로 현재 편집 기준을 유지한다.
- API·DB 스키마·인증 정책은 변경하지 않았다. 신규 패키지는 추가하지 않았다.
- 게스트 취향은 제품 API의 로딩 성공 여부와 무관하게 로컬 저장소 초기화를 시도한다.
- 저장 중에는 입력·뒤로 이동·중복 저장을 막고 실패 시 입력과 오류를 유지한다.

## 검증 범위

새 테스트 7개에서 탭 이동과 뒤로 가기, 56px 하단 바, 실제 선택 수, 게스트 취향 저장과 로그인 진입, 서버 취향 수정 시 비교 보존, 로그아웃 확인·취소, 취향 조회 재시도, 저장 실패, 320px 및 글자 2배 레이아웃을 확인했다.

실제 앱 테마와 Flutter 위젯 렌더링으로 계정·게스트 PNG를 생성해 정렬과 화면 비율을 확인했다. 미리보기의 이메일은 테스트용 계정이다. 일회성 렌더 테스트 파일은 제거했다. Device Hub·시뮬레이터를 직접 조작하지 않았다.
