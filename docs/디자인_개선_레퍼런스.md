# PickWise 앱 디자인 개선

## 범위

현재 Flutter 앱에 적용했다. 기존 초록·흰색·회색 팔레트와 로고 이미지 파일, 제품 사진, 검색·비교·인증·저장 기능을 유지했다. Figma 파일을 수정한 작업은 아니다.

## 확인한 레퍼런스

- [Mobbin](https://mobbin.com/): 공개 앱 화면과 Apple Fitness의 화면 예시에서 주요 콘텐츠를 크게 보여주는 계층, 일정한 아이콘 크기, 제목·보조 정보의 간격을 참고했다. Fitness의 어두운 배경과 강조색은 적용하지 않았다. 회원 전용 전체 앱 흐름을 열람한 것은 아니다.
- [Pttrns](https://app.pttrns.com/patterns): Shopping·Card·Filter & Sort·Login·Bottom Bar 패턴 분류와 공개 목록을 확인했다. 특정 앱의 전체 화면을 그대로 복제하지 않았다.
- Pageflows와 Screenlane은 조회 시 403 응답으로 상세 내용을 확인하지 못했다.

## 적용한 내용

| 영역 | 적용 |
| --- | --- |
| 홈 | 로고·계정 버튼 헤더, 명확한 제목 계층, 검색 입력 영역, 기준 선택 카드, 실제 제품 이미지 중심 가로 카드 |
| 탐색 | 둥근 검색 필드, 정돈된 필터 간격, 브랜드·모델·가격의 구분, 제품 이미지 및 카드 여백 조정 |
| 비교 | 빈 상태 아이콘, 저장 아이콘, 작은 보조 문구 가독성 개선 |
| 상세 | 제품 사진 영역 확대, 제품명·가격 강조, 가격 확인 시점 글자 크기 개선 |
| 로그인 | 화면 제목, 저장 목적 안내, 이메일·비밀번호 아이콘, 입력·행동 간격 정리 |
| 공통 | 기존 팔레트로 입력창·버튼·칩 모양 통일, 하단 탭을 Material 아이콘으로 교체 |

로고 원본 파일은 교체하지 않았다. 홈 헤더 배치에 맞춰 표시 크기만 조정했다. 파란색 사양 강조 등 기존 색상도 그대로 유지했다.

## 검증

- 전체 Flutter 테스트: 56개 통과, 실제 서버 전용 테스트 1개는 환경변수 미지정으로 제외.
- 320px 화면·글자 확대·검색 키보드·탭 이동·제품 비교 관련 기존 회귀 테스트 포함.
- 실제 위젯을 390×844 논리 크기로 렌더링하고 홈·탐색·비교·상세·로그인 PNG를 확인했다. 한글·아이콘 폰트와 제품 이미지 로딩을 포함한 검토다.
- 시뮬레이터나 Figma를 직접 조작한 검증은 하지 않았다. 제품 API와 DB는 이번 디자인 작업의 변경 범위에 포함되지 않는다.
