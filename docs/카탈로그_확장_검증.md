# PickWise 카탈로그 확장 및 검증

확인일: 2026-11-03

## 작업 범위

운영 카탈로그를 3개에서 20개 모델로 확장했습니다. 임시 초안의 제품 수를 그대로 채우지 않고 실제 판매 페이지에서 가격이 표시되는 모델을 골랐습니다. 각 제품에는 가격, 가격 확인일, 제품별 다나와 링크, 실제 사진, 사양별 출처와 확인일이 있습니다.

서버·실시간 가격 API·로그인 기능은 추가하지 않았습니다. 앱은 로컬 JSON과 로컬 사진을 읽습니다.

## 가격과 사양

아래 가격은 공개 제품 페이지의 HTML `og:description`에 있는 최저가를 직접 읽은 스냅샷입니다. 검색 결과에 남은 가격은 사용하지 않았습니다. 배송비 포함 결제금액이나 카드·쿠폰 혜택가를 보장하지 않으며 앱에서 자동 갱신하지 않습니다. 구매 시 제품별 링크에서 다시 확인합니다. 가격이 0원으로 표시되거나 가격비교가 중지된 후보는 제외했습니다.

## 출처 확인 범위

- 가격과 대표 사진: 20개 모두 해당 모델의 실제 다나와 제품 페이지를 확인했습니다. 수집 시각과 페이지·사진의 SHA-256은 [수집 기록](catalog_sources_2026-11-03.json)에 있습니다. 원문 HTML 전체는 저장소에 포함하지 않았습니다.
- 주요 사양: Sony·Samsung·Apple·Soundcore·JBL의 제품 사양, 지원 문서, 설명서와 대조했습니다. 일부 제조사 페이지는 직접 접속이 제한되거나 시간 초과가 발생해 검색 도구로 확인한 제조사 원문 색인 내용을 사용했습니다. 확인일은 조사한 날짜이며 제조사의 갱신일을 뜻하지 않습니다.
- 2차 자료를 사용한 항목: 착용 형태의 한국어 분류는 다나와 표기를 앱 기준으로 정리했습니다. Galaxy Buds FE의 IPX2, Wave Buds 2의 케이스 포함 ANC 켬 32시간, AeroFit 2 AI A3874X의 등록 사양은 해당 모델 다나와 페이지를 출처로 남겼습니다. 일반 AeroFit 2의 공식 사양을 X 모델의 확정 사양으로 대신 적지 않았습니다. 각 필드의 실제 출처는 운영 JSON의 `sourceUrl`을 확인합니다.
- P20i·P30i·P41i·AeroFit 2 AI A3874X의 한 쪽 무게는 이번 확인 범위에서 확정하지 못해 미수록했습니다. 0g이나 추정치를 넣지 않았으며 화면에는 기존의 '정보 없음' 처리를 사용합니다.
- P20i A3949 가격은 해외구매 구성입니다. 모델명과 판매 구성 사양에 해외구매임을 표시했습니다. 국내 정품과 보증·배송 조건이 같다고 가정하지 않습니다.
- 사진 20개를 한 장으로 펼쳐 모델명과 대조했고 Flutter 이미지 디코더로 전부 읽었습니다. 사진 출처는 [사진 목록](../assets/images/products/SOURCES.md)에 정리했습니다. 사진 사용 권한을 별도로 확보한 것은 아닙니다.

## 필터와 배터리 처리

- 예산: 5만원 미만 2개, 5만~15만원 8개, 15만원 초과 10개입니다.
- 착용 형태: 커널형 14개, 세미오픈형 3개, 오픈이어형 3개입니다. 귀걸이형 고정 구조는 AeroFit 2 AI 1개입니다.
- 귀걸이는 귀를 막는 형태와 별개의 고정 구조입니다. `wearType`에는 커널·세미오픈·오픈이어 분류를, `earHook: true`에는 귀걸이 구조를 기록합니다. 따라서 AeroFit 2 AI는 오픈이어형과 귀걸이형 필터에서 모두 찾을 수 있습니다. C40i는 귀걸이가 아닌 이어클립입니다.
- ANC 미지원 모델에는 `batteryHours`와 `maxBatteryHours`를 사용합니다. 기존 ANC 켬 키는 ANC 지원 모델에만 사용합니다. 상세·비교 화면과 추천 이유에 해당 재생 조건을 표시합니다.
- 비교 요약은 재생 조건이 섞여 있으면 배터리 시간 우열을 문장으로 단정하지 않습니다. 표에는 각 제품의 조건과 수치를 함께 표시합니다.
- 같은 브랜드 모델끼리 비교해도 구분되도록 요약에 브랜드 대신 모델명을 표시합니다.
- 추천 계산의 배터리 범위 0~12시간은 유지했습니다. ANC 켬 값이 있으면 우선 사용하고 ANC 미지원 제품은 일반 재생 값을 사용합니다. 서로 다른 시험 조건과 누락 사양 때문에 순위는 참고용입니다. 없는 무게 사양에는 점수를 부여하지 않습니다.
- 용도 태그는 앱의 탐색 분류이며 제조사의 객관적인 성능 점수가 아닙니다.

## 변경 파일

- `assets/data/products.json`: 실제 제품 20개와 필드별 출처.
- `assets/images/products/*.jpg`: 실제 제품 사진 20개.
- `assets/images/products/SOURCES.md`: 모델별 사진 출처.
- `lib/data/models/product.dart`: 재생 시간 사양 조회와 조건 구분.
- `lib/data/models/product_preferences.dart`: 일반 재생 처리, 귀걸이 구조 필터, 조건에 맞는 추천 설명.
- `lib/presentation/screens/product_comparison_screen.dart`: 재생 조건 표기, 혼합 조건의 배터리 우열 문장 제외, 모델명 구분.
- `lib/presentation/screens/product_detail_screen.dart`: ANC 지원 여부에 맞는 배터리·출처 표시.
- `test/`: 카탈로그·화면·필터·비교 회귀 검사 보완.

- 가격 수집 기록과 운영 JSON 20개 일치 검사.
- 제품 사진 20개 디코딩 및 가로·세로 300px 이상 검사.
- 모든 예산대와 네 가지 착용 형태 필터의 후보 존재 확인.
- 비교 목록 저장·복원, 중복·최대 3개 제한, 추천 조건과 후보 수에 독립적인 정렬 검사.
- 320px 폭에서 20개 모델의 상세·가격 화면 총 40개 구성 렌더링 검사.
- 320px 폭에서 ANC 켬·일반 재생 조건이 섞인 3개 제품 비교 검사.
- 작은 화면·키보드·빈 결과·화면 이동·시스템 하단 영역·확대 글자 회귀 검사.
- `dart format`, `flutter analyze`, `flutter test --no-pub`, `flutter build apk --debug --no-pub` 실행.
