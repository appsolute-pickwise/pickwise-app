# PickWise 의사결정 개선 1~3순위

## 이번 범위

최근 추천한 후속 기능 목록의 1~3순위를 구현합니다. 이전 C파트 전용 로드맵의 가격 이력·저장·공유 순서와는 다른 목록입니다.

1. 내 기준에 맞춘 비교 설명
2. 필수 조건·제외 조건
3. 중요도 조절과 결과 변화

사용자가 요청한 대로 A·B·C 파트의 연결까지 확인합니다. 서버·API·패키지는 추가하지 않습니다. 비교 조합 저장·공유, 사용자 프로필 저장, 가격 이력·알림은 이번 범위가 아닙니다.

## 파트별 연결

| 담당 | 확인·수정 범위 | 연결 방식 |
| --- | --- | --- |
| A: 홈·탐색 | 기존 진입·검색·정렬·상품 담기와 하단 탭 상태 유지 확인 | 제품과 선택 목록은 기존 ProductProvider 사용. 홈·탐색 화면 코드는 이번에 변경하지 않음 |
| B: 취향 설정·추천 | ANC 필수, 무게 상한, 기준별 중요도, 빈 결과 원인, 순위 변화 표시 | 취향 설정 → ResultScreen의 초기 preferences. 이후 중요도 변경은 화면 상태와 공통 Provider에 반영 |
| C: 비교·상세·가격 | 선택 기준과 중요도에 따른 비교 설명, 조건 불일치 안내 | ProductProvider.selectionPreferences 조회. 기존 상세·가격 이동 유지 |

## 공통 데이터 계약

ProductPreferences에 다음 선택값을 추가했습니다.

- requireAnc: true이면 ANC 지원이 확인된 제품만 추천합니다.
- maxWeightGrams: 한 쪽 무게 상한입니다. 화면에서 제한 없음·5g·6g·8g을 선택합니다. 상한과 같은 무게는 포함합니다.
- weights: 선택한 기준별 중요도입니다. 1~5이며 미지정 시 3입니다. 기준을 선택하지 않으면 그 기준의 가중치는 순위에 쓰지 않습니다.
- withWeights: 예산·착용 형태·필수 조건을 보존하면서 중요도만 바꿉니다.
- exclusionReasons: 제품 하나가 조건을 만족하지 못한 이유를 반환합니다.
- emptyResultReasons: 일치 제품이 없을 때 조건별 제외 수를 표시합니다. 한 제품이 여러 조건에서 제외될 수 있으므로 수치를 단순 합산하지 않습니다.
- comparisonInsights: 사용자가 고른 기준과 중요도 순서로 제품 간 차이를 설명합니다.

ProductProvider.updateSelectionPreferences는 전달받은 리스트와 맵을 복사해 공유합니다. 화면 밖에서 원본을 바꿔도 공유된 기준은 바뀌지 않습니다. 이 기준은 현재 앱 실행 중에만 유지합니다. 앱 재시작 후의 사용자 설정 저장은 추가하지 않았습니다. 기존 비교 목록의 SharedPreferences 저장은 유지합니다.

## 계산과 예외 처리

1. 예산·착용 형태·필수 조건을 먼저 검사합니다.
2. ANC 필수인데 지원 여부가 없거나, 무게 상한이 있는데 무게 정보가 없으면 조건 만족 여부를 확인할 수 없어 제외합니다.
3. 배터리 / 12, (12 - 한 쪽 무게) / 10, ANC 지원 1·미지원 0, IP 방수 숫자 / 8을 각각 0~1 범위로 제한합니다.
4. 선택한 기준의 점수에 중요도를 곱해 합산합니다. 후보 집합에 따른 min-max 정규화는 사용하지 않습니다. 같은 기준을 중복 입력해도 이중으로 합산하지 않습니다.
5. 합계가 같으면 낮은 가격, 그다음 제품 ID로 정렬합니다.
6. 결과 화면에서 중요도를 바꾸면 즉시 다시 정렬하고 한 번의 슬라이더 조작 시작 시점 대비 후보 순위 변화와 변경 이유를 표시합니다. 드래그 종료 후에도 설명을 유지하고 다음 조작에서는 시작 기준을 새로 잡습니다. 화면을 돌아가도 바꾼 중요도를 유지합니다.

누락 사양의 점수는 0이며 성능이 0이라는 뜻은 아닙니다. 사양이 적은 제품의 순위에 영향을 줄 수 있습니다. 제조사마다 시험 조건도 다르므로 추천 순위는 등록 사양과 사용자의 기준을 반영한 참고 정보입니다.

## 비교 설명

- 배터리: 이어버드 음악 재생 시간을 비교하며 ANC 켬·일반 재생을 구분합니다. 조건이 섞이면 시간 우열을 단정하지 않습니다.
- 무게: 한 쪽 기준으로 비교합니다. 확인되지 않은 모델은 우열 판단에서 제외했다고 설명합니다.
- ANC: 지원·미지원·지원 여부 미확인을 구분합니다.
- 방수: IP 등급의 물 보호 숫자만 비교하며 방진·실제 환경에서의 내구성 전체를 더 좋다고 단정하지 않습니다.
- 배터리가 유리한 제품과 더 가벼운 제품이 다르면 각각의 장점을 함께 보여줍니다. 특정 제품을 모든 면에서 우수하다고 표시하지 않습니다.
- 새로운 기준과 기존 비교 목록이 다르더라도 사용자 선택을 지우지 않습니다. 제품 한 개만 담겨 있어도 조건 불일치 원인을 표시합니다.

## 주요 변경 파일

- lib/data/models/product_preferences.dart: 필수 조건·가중치·제외 원인·비교 근거.
- lib/presentation/providers/product_provider.dart: 현재 조건의 공통 공유.
- lib/presentation/widgets/importance_controls.dart: 취향·추천에서 함께 사용하는 중요도 입력.
- lib/presentation/screens/liking_screen.dart: 필수 조건과 중요도 선택·복원.
- lib/presentation/screens/result_screen.dart: 실시간 재정렬·변경 설명·빈 결과 원인.
- lib/presentation/screens/product_comparison_screen.dart: 개인 기준과 중요도 표시·조건 불일치 설명.
